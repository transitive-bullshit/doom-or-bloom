# Research records

Keep concise decisions, methods, validation summaries, and inputs required by tests in this directory. Canonical simulated-user evidence lives in `lib/journeys/*personas.ts`.

Store extensive per-user research packets, raw evidence JSON, search results, generated coverage diagnostics, and regeneration details in git-ignored `work/research/`. These are local working material and are not required to build or test a fresh checkout. Historical summaries may name local artifacts that are unavailable on other machines.
