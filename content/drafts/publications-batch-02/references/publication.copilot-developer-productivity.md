## Neutral context

A controlled task-level developer-productivity experiment.

## Reported facts

Peng and colleagues conduct a controlled experiment in which recruited developers implement a JavaScript HTTP server. The Copilot treatment group completes that specified task 55.8% faster than the control group. The authors report heterogeneous effects across developers.

## Interpretations

A task-completion speed gain has a narrower scope than whole-job productivity.

## Known unknowns

A short, specified programming task does not measure whole-project maintenance, production security, or long-run labor demand.

## Claim support

Supports a causal task-completion improvement in this experiment. Does not show every developer becomes 55.8% more productive across all work or that coding jobs become unnecessary.
